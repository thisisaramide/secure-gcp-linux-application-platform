# Secure GCP Linux Application Platform

A hands-on portfolio project demonstrating Linux system administration, GCP cloud infrastructure, automation, containerization, Kubernetes fundamentals, and cloud-security practices.

## Project goal

Build and secure an internal inventory application for a fictional small company. The platform will begin on a hardened Linux virtual machine and later be deployed as a containerized application in Google Kubernetes Engine.

## Skills demonstrated

- Linux administration and system hardening
- User, group, package, storage, service, and SSH management
- Bash scripting and automation
- Git and documentation
- GCP networking, IAM, logging, monitoring, and backups
- Terraform and Ansible
- Docker and Kubernetes
- Vulnerability management and cloud-security controls

## Planned phases

1. Build and harden a Linux VM
2. Configure Nginx and an internal application
3. Automate configuration with Bash and Ansible
4. Provision GCP infrastructure with Terraform
5. Add monitoring, backups, and incident runbooks
6. Containerize the application with Docker
7. Deploy to GKE
8. Document security controls and a threat model
